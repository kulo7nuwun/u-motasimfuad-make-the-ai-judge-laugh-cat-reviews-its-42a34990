# Make the AI Judge Laugh: Cat Reviews Its Human

A tiny Python program that writes one funny single-line one-star review
from a house cat about its human to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## The entry

> One star. My human bought a $400 bed. I sleep in the box it came in.
> He cried. I have filed this review from the box, where I live now.
